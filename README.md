🚖 Uber Ride Analytics Dashboard

An interactive Uber Ride Analytics Dashboard built with Power BI to analyze ride performance, revenue trends, ride completion rates, customer ratings, and location-based booking insights.

dashboard_screenshot.png

📌 Project Overview

This dashboard provides a comprehensive analysis of Uber ride operations by visualizing key business metrics such as:

Total completed rides
Lost rides
Revenue generated
Total distance traveled
Average trip distance
Driver and customer ratings
Monthly ride trends
Vehicle category performance
Pickup and drop location analysis

The goal of this dashboard is to help stakeholders monitor operational efficiency, identify performance trends, and make data-driven decisions.

📊 Dashboard Features
1. Ride Status Analysis

Visual representation of ride outcomes:

✅ Completed Rides
❌ Cancelled Rides
⏳ Incomplete Rides

These KPIs help identify operational bottlenecks and service reliability.

2. Monthly Ride Trend Analysis

Area chart displaying ride count across months to identify:

Peak demand periods
Seasonal patterns
Performance fluctuations

Insight: Ride volume remains relatively stable with moderate fluctuations throughout the year.

3. Monthly Booking Distribution

Bar chart showing completed bookings month-wise.

Used for:

Trend monitoring
Demand forecasting
Capacity planning
4. Vehicle Category Performance

Comparison of completed bookings by vehicle type:

Auto
Bike
Go Mini
Go Sedan
Premier Sedan
Uber XL

Insight: Auto and Bike categories contribute the highest number of completed rides.

5. Ratings Analysis

Measures service quality using:

Average Driver Rating
Average Customer Rating

These indicators help evaluate customer satisfaction and driver performance.

6. Location Intelligence
Pickup Location Analysis

Tracks completed bookings by pickup point.

Example:

Pickup Location	Completed BookingsKhandsa	600
Drop Location Analysis

Tracks completed bookings by destination.

Example:

Completed rides significantly exceed incomplete ride categories.
Revenue generation remains strong despite ride cancellations.
Auto and Bike services dominate ride demand.
Average ratings above 4.0 indicate positive customer experience.
Certain pickup and drop locations consistently generate high booking volumes.
Monthly booking patterns can be used for demand forecasting.
